Flow — OnTheBridge Playlist

ไม่ต้องใช้ API ของค่าย — ใช้ TMDb + MusicBrainz + AI แนะนำ

1
User ค้นหารายการ
พิมพ์ชื่อหนัง/ซีส์/เพลง → แอปค้นจากฐานข้อมูลภายนอก (ไม่ใช่ API ค่าย)
TMDb (หนัง/ซีส์) MusicBrainz (เพลง) ค้นหาได้ทันที
2
User เลือกรายการที่ต้องการ
แอปแสดงผลลัพธ์จาก TMDb/MusicBrainz → User คลิกเลือก → บันทึกลง DB
เลือกเอง ไม่มี API ค่าย
3
บันทึก + ระบุแพลตฟอร์ม
User เลือกว่ารายการนี้อยู่บนแพลตฟอร์มไหน (Netflix/Disney/YouTube...)
หนัง/ซีส์ Netflix, Disney+, HBO, Prime, WeTV, VIU, iQIYI, Youku...
เพลง Spotify, Apple Music, YouTube...
อนิเมะ/ซีรีส์จีน BiliBili, iQIYI, Youku...
4
แสดง Playlist ตามหมวด
รายการทั้งหมดแยกตามประเภท — ดูได้ทันที
ภาพยนตร์ ซีส์ สารคดี ทอล์คโชว์ เพลง ข่าว
5
AI วิเคราะห์ + แนะนำรายการเพิ่ม
AI ดูรายการที่ User เคยบันทึก → แนะนำรายการคล้ายกันจาก TMDb/MusicBrainz (ไม่ต้องดึงจากค่าย)
DeepSeek (ฟรี) แนะนำจากรายการเดิม
หมายเหตุ: ไม่ต้องใช้ API ของ Netflix/Disney/HBO/Prime/WeTV/VIU/iQiYi เลย — ใช้ TMDb + MusicBrainz + AI แทน ฟรีและถูกกฎหมาย [ตรวจสอบ: พบ 1 แหล่ง]
